# SPEC-0031: Skill index, safety tiers and a Well-Architected security mapping

**Status**: Implemented (pending CI)
**Date**: 2026-10-18

## What

Three small additions, taken from ideas in Google's open-source `google/skills` repository (reviewed, not installed):

1. A machine-readable list of the repo's skills, `skills/index.json`, generated from the SKILL.md files and kept in
   sync by a test.
2. A "Safety tiers" section on the two skills that run commands or change code (`self-heal`, `security-review`), so an
   agent knows which steps it may run freely and which need a person's approval.
3. `docs/WELL_ARCHITECTED_SECURITY.md`: the Google Cloud Well-Architected security pillar's principles, each mapped
   to evidence in this repo, with the gaps and the Google-Cloud-only items stated plainly.

## Why

The owner works with Google Cloud and wants the repo to read well to AI agents and to reviewers. Google publishes an
`index.json` of skills (name, description, entrypoint) so agents can discover them without crawling folders; this repo
has nine skills and no such list. Its eval and security skills also separate read-only steps from costly or
side-effecting ones, which this repo's rules already imply but its skills never state.

## Decisions

- Nothing from `google/skills` is copied or installed. Those skills operate Google Cloud products this site does not
  use, and third-party skills would widen the reviewed skill boundary (see `docs/SKILL_SECURITY_SCOPE.md`).
- The index has the same three fields as Google's (`name`, `description`, `entrypoint`), with raw GitHub URLs. It is
  generated by `scripts/generate-skill-index.mjs`; a test fails when the committed file is stale.
- `skills/prasad-portfolio/SKILL.md` is pinned by SHA-256 and is not touched.
- The mapping doc is a self-assessment, like `docs/SECURITY_THREAT_MODEL.md`: no certification claim, and each item
  names a file or workflow that exists.

## Scope boundaries

- In scope: the generator, `skills/index.json`, its test, two skills' safety-tier sections, the mapping doc.
- Out of scope: linking the index or the doc from `llms.txt`, the AI-agent manifest or the site (those are
  positioning and metadata files; a follow-up if wanted), any CI change (the test covers drift), Gemini or other
  providers.

## Evidence to reuse

`skills/*/SKILL.md`, `scripts/verify-deploy.mjs` (script plus test pattern), `docs/SECURITY_THREAT_MODEL.md`,
`evaluations/security.yaml`.
